# Live Rank TikTok

Ranking interativo para TikTok Live com TOP 10 TAP, TOP 10 Presentes, TOP 3 Doadores e destaque animado do ultimo campeao.

## Rodar localmente

```bash
npm install
npm start
```

Abra:
- Tela da live: `http://localhost:8091/`
- Painel admin: `http://localhost:8091/admin.html`

## Render

O projeto inclui `render.yaml` e endpoint de saude em `/health`.

Configuracao principal:
- Build: `npm install`
- Start: `npm start`
- Node: `22.22.x`
- Health check: `/health`
